Important Network Concepts

IP Address

A unique numerical address used to identify a device on a network.

Example: 192.168.1.10

Router

A networking device that forwards data between different networks.

Protocol

A set of rules that defines how devices communicate.

Packet

Data is divided into small units called packets before transmission.

TCP/IP

A group of protocols used for communication over the Internet.

DNS

Converts human-readable domain names into IP addresses.
