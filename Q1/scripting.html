Client-side vs Server-side Scripting

Understanding where web code is executed

Client-side Scripting

Client-side scripting refers to code that runs in the user's web browser. It is mainly used to create interactive and responsive webpages.

Examples

  • HTML
  • CSS
  • JavaScript

Uses

  • Form validation
  • Animations
  • Button interactions
  • Dynamic webpage changes

Server-side Scripting

Server-side scripting refers to code that runs on the web server. It is used for processing data, business logic, authentication and database operations.

  • Database operations
  • User authentication
  • Processing forms
  • Business logic
  • Generating dynamic content

Comparison

Client-side Scripting Server-side Scripting
Runs in the web browser. Runs on the web server.
Mainly handles user interface. Mainly handles application logic.
JavaScript is commonly used. PHP, Python, Java and Node.js are examples.
Can provide immediate interaction. Usually requires communication with the server.
Used for animations and form validation. Used for databases and authentication.
Code is generally delivered to the browser. Server-side code is executed on the server.
