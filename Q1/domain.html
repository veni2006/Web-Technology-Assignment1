Domain Name

Understanding website names and DNS

What is a Domain Name?

A domain name is a human-readable name used to identify a website on the Internet.

Instead of remembering a numerical IP address, users can enter an easy-to-remember domain name.

Example

🌐
example.com
→
DNS Server
→
93.184.216.34

What is DNS?

DNS stands for Domain Name System. DNS translates domain names into IP addresses so that computers can locate the correct server.

Domain Name Structure

www.example.com
www Subdomain
example Domain Name
.com Top-Level Domain

Common Domain Extensions

.com

Commonly used for commercial websites.

.org

Commonly used by organizations.

.edu

Commonly associated with educational institutions.

.gov

Used by government organizations.

.in

Country-code domain for India.

.net

Originally associated with network organizations.
