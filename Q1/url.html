URL and its Structure

Understanding web addresses

What is a URL?

URL stands for Uniform Resource Locator. It is the address used to locate a resource on the Internet.

A resource can be a webpage, image, video, document or another online resource.

https://www.example.com:443/course/index.html

Structure of a URL

https Protocol
www Subdomain
example.com Domain
443 Port
/course/ Path
index.html File

URL Components

Component Meaning
Protocol Defines how the browser communicates with the server.
Subdomain A subdivision of the main domain.
Domain Identifies the website.
Port Identifies a communication endpoint.
Path Specifies the location of a resource.
File Specifies the particular resource being requested.
